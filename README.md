UrbanDelivery - Microservicio de Promociones

Estudiantes: Luis Ahumada, Maximiliano Valenzuela, Litzy Zuñiga

Descripción del proyecto:
Este microservicio maneja todo lo que son los descuentos y promociones de UrbanDelivery. La idea es que actúe como proveedor para que otros servicios le pregunten de cuánto es el descuento antes de cobrar.

Funcionalidades implementadas:
- crear promociones nuevas con su porcentaje de descuento
- listar todas las promos o filtrar para ver cuáles están activas ahorita
- editar promos existentes o borrarlas

Pasos para ejecutar:
1. tener mysql corriendo localmente.
2. clonar o descargar el proyecto y ejecutarlo en el ide.
3. el servicio se levanta en el puerto 8084, creando la tabla promociones_db automáticamente.
4. probar los endpoints en postman.
